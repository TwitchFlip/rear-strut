# Rear strut 200CIII

Phone app showing the Kress 200CIII rear suspension cylinder: empty and loaded ride, levelling, and the hang-up fault step by step, with the "Unstick the separator" and "Set or reset precharge" procedure sheets.

Open the GitHub Pages link in Chrome on Android, then menu → **Install app**. It opens full screen from the home screen and works offline after the first load.

Drawn after Kress 098455 (Systems Operation, Testing and Adjusting). The unstick procedure is not a Kress procedure.
